# BXI 50L夹爪毫米协议与Native66合同（2026-10-22）

当前控制 `20261027-demo-05-exit-disable`，采集仍为v17。毫米demo04已有现场记录；demo05退出失能补丁已离线验证，尚未安装/验证真机。适用官方夹爪固件0.3.x/1.4.x，不能用于旧角度固件或普通关节电机固件。

## 使用行为

- 进入SONIC：两侧各发一次使能；发送零KP/KD/前馈的普通MIT帧取得反馈，然后从实测位置跟随到70mm。反馈到70±0.5mm即准备完成。这是“打开准备”，不重新寻零、不写零位、不碰机械端点。
- 左PICO扳机→CAN5，右PICO扳机→CAN6，节点均为1。目标开口=70×(1−扳机深度)mm，松开70、按到底0。
- 两侧独立控制。一侧没反馈不阻止另一侧打开；无首帧3秒、运行反馈超过300ms或温度≥80°C时只停止故障侧。无自动重新使能，无全身零力矩请求。
- 退出SONIC（包括normal、pd_brake、zero_torque）对本次使能过的夹爪发送失能帧，不额外打开/闭合；重新进入重新使能并打开70mm。A+X只暂停POSE仍留在SONIC，不触发失能。扳机过期250ms时保留现有位置保持逻辑。
- DM后端、身体策略和完整10帧输入管理没有改变。

## 参数与编解码

参数文件是库根 `bxi_gripper_mm.json`，由 `bxi_gripper_protocol.py` 读取；不再在C中写死参数。`mod.yaml`的DM KP/KD不控制BXI。

| 项目 | 当前值 |
|---|---|
| 应用开口范围 | 0～70 mm |
| 位置线协议范围 | 0～90 mm，16bit；固件保护上限80.55 mm |
| KP / KD | 官方推荐2 / 0.05；线协议范围0～5 / 0～1 |
| 前馈力 | 0 N；反馈力单位N，正号表示闭合 |
| 跟随速度 / 加速度 | 326.6667 mm/s / 6533.3333 mm/s² |
| CAN | 标准ID1，回复0x11，CANFD+BRS，8字节；已有硬件链路1M/5M |
| 温度 | 继续采用默认NTC；要求AUX关闭 |

速度/加速度按旧版本全行程时间折算：70×1400/300及70×28000/300。只用于保留跟随快慢，**不是电机角度与开口的物理换算，也不用于转换旧训练数据**。同事原STREAM算法源码未改；C桥接只换单位、编码范围及参数入口。默认max_vel寄存器45rad/s，据官方公式四舍五入得到速度映射±641mm/s；官方正文另写约642。50L电流默认14.6667/3A，公式得到力映射±24.01565N，正文约24.03。实际寄存器/构建若不同，必须同步JSON，安装器不读写寄存器。

新桥接ABI为2，旧ABI1动态库被拒绝。官方40mm示例帧 `71 C6 7F F6 66 0C C7 FF` 已逐字节核对。使能FC、失能FD语义不变；程序不发送FE写零。

## 采集、训练和推理合同

合同ID：`elf3_native66_bxi_opening_mm_v2`。单位身份为 `absolute_gripper_opening` / `mm`，沿用ELF3_NATIVE_1D / slot14；没有新增模态或自由度。

| 数据项 | 内容/单位 |
|---|---|
| Parquet observation.state[0:29] | 身体29关节实测rad |
| observation.state[29:31] | 左、右夹爪反馈开口mm |
| observation.projected_gravity[0:3] | 单位重力向量 |
| action.motion_token[0:64] | 真实SONIC推理token |
| action.wbc[0:29] | 身体29关节下发目标rad |
| action.wbc[29:31] | 左、右实际发送的开口目标mm（平滑后线协议值） |
| 三路RGB | 原分辨率MP4；相机30Hz，沿用最近图像组成目标50Hz实际推理行 |

GR00T模型状态34维=身体29+实测开口2+重力3；模型动作66维=token64+目标开口2。KP/KD、速度、力、温度是控制/诊断信息，不增为训练动作。夹爪不经过SONIC decoder。

ROS `/sonic/gripper_sample` 使用schema2和合同ID，字段 `opening_mm`、`velocity_mm_s`、`force_n`，命令为 `command.position_mm`。数采拒绝旧rad遥测，避免同样维度混入不同单位。DM遥测保留schema1/rad；本native66-mm录制入口明确面向双BXI，DM需使用原独立合同。

仍使用官方录制状态、MP4/Parquet写入、暂停段清理、弃用排除和统计。暂停前后留在同一训练episode，40步窗口可跨接缝。v15接收/写盘解耦保留。

训练必须重新生成毫米数据统计。训练入口、恢复训练和推理核查数据/processor的合同ID、坐标和单位，旧弧度或仿真模型不可仅改标签使用；从干净N1.7基础模型后训练。现有旧数据及冻结v15工具保留，不自动换算、不覆盖。原始数据导出后才使用训练入口。

推理在反归一化后直接输出mm，执行适配器限制0～70mm；NPZ输入/输出带 `contract_id` 和 `gripper_position_unit` 标量字符串。远程Policy返回同样身份。硬件适配要求直接mm，scale=1、direction=1、offset=0。通用GR00T同步循环原有“禁止直接在线真机执行”限制保留，尚未验证GR00T闭环任务。
