## 问题与变化

相机USB掉线时旧版会结束整套数采，设备插回后也不会恢复监听。v17将现有相机/记录器入口改为常驻恢复管理，分类记录中止原因。缺失/占用设备每5秒检查；子进程退出时先通知记录器收尾，再恢复后台。仅管理本数采创建的腕部相机和记录器。

录制中相机超过2秒未更新会中止本条。判断使用消息接收时间，不把header时间戳偏差当作断线，也不恢复过去30ms配对丢行门槛。ROS接收、队列过载、编码/写盘、磁盘空间及手动停止分别记录原因；输入缺项、按键接收/拒绝原因加入状态日志。

已写数据保留并标为interrupted，官方写入器仍负责视频/Parquet收尾；磁盘/编码损坏时不保证文件完整，必须离线检查。新监听器等待按键释放及新的开始操作，不自动续录异常条。A+X正常暂停/恢复仍属于同一条数据。systemd异常退出恢复采用Restart=on-failure；人工stop后保持停止。

不修改身体策略、模型、10帧输入管理、PICO模式切换、夹爪控制或毫米训练合同；官方RecordingCommands/Exporter源码未改。
